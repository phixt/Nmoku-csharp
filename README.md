# Nmoku (Gomoku 613B-E2D → Godot C#)

6×13×13 三维五子棋的 Godot 4 (.NET/C#) 迁移版，源项目：`gomoku-613B-E2D`（TypeScript + Three.js + Tauri）。

- 迁移计划：[docs/migration-plan.md](docs/migration-plan.md)
- 目标平台：Windows 桌面 x64
- 引擎：Godot 4.6.x .NET 版 + .NET 8

当前处于 M0（环境搭建）阶段，尚无可运行工程。
