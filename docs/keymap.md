## 存档操作语义（批9 定稿 2026-09-26：菜单=档案管理，不承担保存当前对局）

- **写局只走键盘**：**S 键 = 保存进度**（落入首个空槽，全满则覆盖快存槽；不弹确认，源 `saveGame`
  语义）；**Ctrl+S = 快存**（第 6 槽）；**Ctrl+L = 读快存**（暂停态恢复检查点；§3.4 读档仅
  Title/Paused 合法，对局中先 Esc）。
- **存档菜单（标题/暂停可开）**：
  - 头部「导入」：.nzsave 文件 → 统一落槽 = 第一个空槽；全满则覆盖最后一个非快存槽（槽 5）并确认。
    快存槽永不被统一导入覆盖。原头部剪贴板「导入」删除（由逐槽「填写/覆盖」取代）。
  - 空槽行：[填写]（剪贴板→该槽）[导入]（文件→该槽）。
  - 非空槽行：[读取][复盘][覆盖]（剪贴板→该槽，占用先确认）[复制]（槽→剪贴板）[导出]（槽→.nzsave
    文件，文件对话框直开）[删除]。
  - 剪贴板=显式中转站：「复制 ↔ 填写/覆盖」构成搬运闭环——导出到剪贴板后可写回任意指定槽位。
    源「覆盖」（把当前对局写入槽位）语义整体退役；导入原档保真（id/timestamp 随档）。
- **暂停菜单「读档」按钮**：打开存档管理菜单；**L 键仍是读最新**（源 esc-load 快路径语义），两者并存。
- 自定义连珠数随档恢复：走 .nzsave manifest 与槽位 index 外圈元数据（B14）。
- **偶数阶存档不合法**（2026-09-26 拍板）：SaveValidator 拒绝偶数 boardSize（错误码
  `SAVE_INVALID_EVEN_BOARD_SIZE`），校验覆盖磁盘槽位载入与剪贴板/文件/zip 全部导入入口——
  前提：存档格式不与外部游戏互通 + 沙盒/预设无偶数阶入口，全链路封闭偶数阶。

## 路由关系图

层级栈（z 序）：`L0 基座(0) → L1 模态(10) → L2 浮层(20) → 对话框(30)`。

```
┌── L2 浮层（叠加在当前栈之上，Esc 关最顶；F1 切帮助）────────────────────────┐
│   help(F1·任意态·不透明)   save-menu(标题/暂停上·dim)   replay-hud(仅复盘·无背板) │
└────────────────────────────────────────────────────────────────────────────┘
        ▲ F1                        ▲ 标题/暂停菜单打开               ▲
┌── L1 模态（背板 dim+blur，切出销毁重建）────────────────────────────────────┐
│   pause(对局中 Esc/R)    game-over(胜负自动)    guide(不透明,标题/暂停两入口)   │
└────────────────────────────────────────────────────────────────────────────┘
        ▲                            ▲                      ▲
┌── L0 基座（互斥；KeepAlive：title/game 常驻，仅切可见性）─────────────────────┐
│      title（不透明）         ⇄          game（分屏棋盘 + HUD）               │
└────────────────────────────────────────────────────────────────────────────┘
```

状态机 → 路由栈投影（唯一映射点 `SceneRouter.StackFor`）：

| GameState | 路由栈（底→顶） |
|---|---|
| Title | [title] |
| Playing | [game] |
| Paused | [game, pause] |
| GameOver | [game, game-over] |
| GuideFromTitle | [title, guide] |
| GuideFromGame | [game, guide] |
| Replay | [game, replay-hud] |

浮层独立于状态机：save-menu 叠在 Title/Paused 上，help 叠在任意栈上；状态切换时浮层自动收起。

## 层级切换的保留/销毁策略（改 `RouteDef.KeepAlive` 即改行为）

| 路由 | KeepAlive | 语义 |
|---|---|---|
| title | ✅ 保留 | 常驻，被上层遮挡时仅隐藏 |
| game | ✅ **保留现场**（人类拍板 2026-09-19） | 切回标题不销毁棋局/相机/视图；"继续对局"直接恢复；"开始新局"覆盖前先确认 |
| pause / game-over / guide | ❌ 销毁 | 轻 UI，进出重建 |
| save-menu / help | ❌ 销毁 | 浮层，关闭即释放 |
| replay-hud | ❌ 销毁 | 复盘 HUD 附件 |

## 输入分派规则

1. 模态对话框（z=30）打开：吞掉一切游戏快捷键（§4.1）。
2. L2 浮层打开：只响应 `AllowWhenOverlay` 键（F1 切帮助、Esc 关最顶浮层）。
3. 引导态 Esc：标题入口=返回标题，对局入口=回对局。
4. **单次动作全部事件驱动**（`_Input` 键事件 + echo 过滤）：**按一下动一次，按住不重复**
   （Q/E 与 A/D 同语义；键回显不再造成重复触发——180° 旋转抽搐根因）。同键跨态按 KeymapTable
   声明序取本状态下合法的动作（R 在对局=暂停、暂停=重开、复盘=退出）。
5. 相机/间距类持续按住键（W/S、Shift+WASD、Z/C、滚轮）按 context 门控（PLAYING+REPLAY）按住生效。

## 分辨率与高分适配（B16 v4，2026-09-25）

- 窗口固定 **1920×1080**（项目默认，`ApplyDisplayScaling` 不再按工作区调整），内容缩放
  `UiScaleFactor=2.5` 绝对值 → 等效设计基准 768×432，UI 物理字号 = 基准 ×2.5。
- **3D 子视口（B16 v4 定稿）**：`GameScreen.ViewportHost` 自绘宿主（Control 画视口纹理），
  视口 Size=宿主逻辑尺寸×内容缩放=物理像素，纹理与屏幕 1:1。
  - v1 教训：SubViewportContainer(stretch=false) 手动喂尺寸 → 容器最小尺寸=视口尺寸 →
    每帧 ×缩放正反馈回环（黑屏事故，migration-plan §10 B16）。
  - v2 教训：Scaling3DScale 超采样降采样回逻辑纹理——纹理仍被放大显示，高缩放下发糊。
  - v3 教训：`_GetMinimumSize` 清零无效——C++ 侧 get_minimum_size 不经脚本虚方法。
  - v4：弃用 SubViewportContainer，结构性解耦（宿主最小尺寸恒零）。
- 启动日志 `display:` 行输出 window/screen/dpi/canvasScale/3D 视口，用于诊断。
